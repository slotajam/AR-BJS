# คู่มือผู้ใช้: Research Intelligence Platform

ระบบนี้ช่วยค้นหา คัดกรอง และจัดอันดับงานวิจัย โดยตรวจสอบย้อนกลับได้ทุกขั้นตอน
ทุกผลการค้นหา ข้อมูลเมตา ไฟล์ PDF ข้อความที่ยกมา และคะแนน บอกได้เสมอว่ามาจากแหล่งใด
ดึงมาเมื่อไร และได้รับอนุญาตให้ใช้บนพื้นฐานใด

## 1. ติดตั้งและเปิดระบบ (ผู้ดูแลระบบ)

สิ่งที่ต้องมี: คอมพิวเตอร์หรือเซิร์ฟเวอร์ที่ติดตั้ง Docker แล้ว และเชื่อมต่ออินเทอร์เน็ตได้

```bash
git clone <repository> && cd AR-BJS/research-intel
./rip.sh start      # ครั้งแรกจะสร้างไฟล์ .env และรหัสลับแบบสุ่มให้อัตโนมัติ
```

เมื่อเห็นข้อความ `Research Intelligence is running: http://localhost:8080` ให้เปิดลิงก์นั้นในเบราว์เซอร์

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `./rip.sh admin` | สร้างบัญชีผู้ใช้ |
| `./rip.sh verify` | ทดสอบการเชื่อมต่อ OpenAlex / Crossref จริง (ควรรันหลังติดตั้งครั้งแรก) |
| `./rip.sh status` | ดูสถานะระบบ |
| `./rip.sh backup` | สำรองฐานข้อมูลและไฟล์ PDF |
| `./rip.sh stop` | ปิดระบบ (ข้อมูลไม่หาย) |
| `./rip.sh update` | อัปเดตเป็นเวอร์ชันล่าสุด |

หากไม่ระบุโดเมน ระบบจะเปิดให้เข้าใช้ได้จากเครื่องเซิร์ฟเวอร์เองเท่านั้น (`127.0.0.1:8080`)

### เปิดเป็นเว็บไซต์บนโดเมนของคุณ (HTTPS)

1. เช่าเซิร์ฟเวอร์ Linux (Ubuntu สเปกอย่างน้อย 2 vCPU, RAM 4 GB, ดิสก์ 40 GB) แล้วติดตั้ง Docker:
   `curl -fsSL https://get.docker.com | sh`
2. ที่ผู้ให้บริการโดเมน สร้าง **A record** เช่น `research.yourdomain.com` ชี้ไปที่ IP ของเซิร์ฟเวอร์
3. เปิดพอร์ต 22, 80 และ 443 ทั้งใน firewall ของผู้ให้บริการคลาวด์ และบนเครื่อง
   (`ufw allow 22,80,443/tcp && ufw enable`)
4. รันคำสั่ง:
   ```bash
   ./rip.sh start --domain research.yourdomain.com --email you@yourdomain.com
   ./rip.sh admin      # สร้างบัญชีแรก (เว็บสาธารณะจะปิดการสมัครเองไว้เป็นค่าเริ่มต้น)
   ```
5. เปิด `https://research.yourdomain.com` ในเบราว์เซอร์

ระบบจะขอใบรับรอง HTTPS จาก Let's Encrypt และต่ออายุให้อัตโนมัติ
ถ้าเปิดเว็บไม่ได้ ให้ตรวจว่า DNS ชี้มาที่เซิร์ฟเวอร์แล้ว และพอร์ต 80/443 เปิดอยู่
แล้วดูความคืบหน้าของการออกใบรับรองด้วย `./rip.sh logs caddy`
(รายละเอียดเพิ่มเติม: `docs/OPERATIONS.md` และ `docs/SECURITY.md`)

## 2. เริ่มใช้งาน

1. **สมัคร / เข้าสู่ระบบ**: รหัสผ่านต้องยาวอย่างน้อย 10 ตัวอักษร ถ้าใส่ผิดเกิน 10 ครั้ง
   ระบบจะล็อกการเข้าสู่ระบบไว้ 15 นาที
2. **สร้างโครงการ**: ตั้งชื่อ และใส่ "คำถามวิจัย" ซึ่งระบบจะใช้เป็นคำค้นตั้งต้นในการจัดอันดับ
3. **เชิญสมาชิก** (แท็บ *Members & audit*):
   - viewer: ดูและส่งออกข้อมูลได้
   - editor: ค้นหา นำเข้า อัปโหลด และจัดอันดับได้
   - admin: จัดการสมาชิกได้
   - owner: ทำได้ทุกอย่าง รวมถึงลบโครงการ

## 3. ค้นหางานวิจัย (แท็บ *Searches*)

- ใส่คำค้น คำสำคัญ คำพ้อง (หนึ่งบรรทัดต่อหนึ่งคำ เช่น `battery: cell, accumulator`) ช่วงปี ภาษา
  และประเภทเอกสาร
- **Exclusion terms**: คำที่ถ้าพบในชื่อเรื่องหรือบทคัดย่อ ระบบจะติดป้ายว่า "excluded" ให้อัตโนมัติ
  (ระบบไม่ลบรายการทิ้ง ยังเปิดดูได้)
- **PDF acquisition**:
  - *Metadata only*: เก็บเฉพาะข้อมูลบรรณานุกรม
  - *Collect permitted open-access PDFs*: ดาวน์โหลดเฉพาะ PDF ที่มีสิทธิ์อย่างชัดเจน
- ระหว่างค้นหาจะเห็นแถบความคืบหน้า กด **Cancel** เพื่อยกเลิก หรือ **Retry / Resume**
  เพื่อทำต่อจากจุดที่ค้างไว้ได้ ระบบจะไม่ดึงข้อมูลซ้ำ
- ในแต่ละรอบการค้นหา ระบบบันทึก "คำค้นที่ส่งจริง" แยกตามแหล่ง
  - Crossref ไม่รองรับ AND / OR / NOT ระบบจึงตัดตัวดำเนินการเหล่านี้ออกก่อนส่ง
    และแสดงคำค้นจริงให้เห็น
  - ถ้าแหล่งใดล้มเหลว ระบบจะแจ้งไว้ แต่แหล่งอื่นยังทำงานต่อได้

## 4. คลังเอกสาร (แท็บ *Library*)

- **discovery** = มีเฉพาะข้อมูลบรรณานุกรม ยังไม่มี PDF
- **collected** = มี PDF ที่ผ่านการตรวจสอบแล้ว และมีสิทธิ์ใช้งาน
- สถานะการเข้าถึง (Access):

  | สถานะ | ความหมาย |
  |---|---|
  | `permitted_available` | ดาวน์โหลดได้โดยชอบ |
  | `access_restricted` | ไม่มีสิทธิ์ ระบบจะไม่ดาวน์โหลด |
  | `unavailable` | ไม่มี PDF |
  | `invalid_pdf` | ไฟล์ที่ได้มาไม่ใช่ PDF จริง |

- เลือกหลายรายการแล้วกด **Collect permitted PDFs** เพื่อดาวน์โหลดเฉพาะที่มีสิทธิ์
- ดับเบิลคลิกแถวเพื่อเปิดดูรายละเอียด
- เครื่องหมาย "—" หมายความว่าไม่มีแหล่งข้อมูลใดให้ค่านี้มา (ระบบไม่เดาค่าแทน)

## 5. นำเข้าและอัปโหลด (แท็บ *Import / upload*)

- นำเข้าได้จาก รายการ DOI, BibTeX, RIS หรือ CSV
- ระบบตรวจรายการซ้ำตามลำดับ DOI → รหัสของแหล่งข้อมูล → ชื่อเรื่อง ผู้แต่ง และปี
  รายการที่ไม่แน่ใจจะส่งให้ผู้ใช้ตรวจเอง ไม่รวมให้อัตโนมัติ
- อัปโหลด PDF ได้เอง แต่ต้องเลือก "พื้นฐานสิทธิ์" และติ๊กยืนยันว่ามีสิทธิ์ใช้ไฟล์นั้น
  ถ้าเคยอัปโหลดไฟล์เดียวกันแล้ว ระบบจะรู้จากค่า checksum

## 6. อ่านเอกสารและเก็บหลักฐาน (หน้ารายละเอียดเอกสาร)

- **ด้านซ้าย**: หน้า PDF แต่ละหน้า
- **Evidence**: พิมพ์คำที่ต้องการหาแล้วกด *Find* ระบบจะแสดงข้อความที่ตรงกัน คลิกข้อความนั้น
  แล้วหน้า PDF จะเลื่อนไปยังตำแหน่งนั้นและไฮไลต์สีเหลืองให้
  ข้อความเหล่านี้คือคำที่ตรงกันจริงในเอกสาร ไม่ใช่ข้อสรุปที่ AI สร้างขึ้น
- **Text**: ลากเลือกข้อความแล้วกด *Save selection as evidence* เพื่อเก็บเป็นหลักฐาน
  ระบบจะบันทึกเลขหน้าและตำแหน่งตัวอักษรไว้
- แท็บอื่น ๆ ได้แก่
  - **Provenance**: แหล่งที่มาของข้อมูล
  - **Access & file**: สิทธิ์ สัญญาอนุญาต และ checksum ของไฟล์
  - **Notes**: บันทึกของผู้ใช้
- **การแก้ไขข้อมูล**: การแก้ไขของผู้ใช้เก็บแยกจากค่าเดิมของแหล่งข้อมูล ค่าเดิมไม่ถูกเขียนทับ
- **ข้อจำกัดของระยะที่ 1**: ระบบยังไม่ดึงตาราง สมการ หรือรายการอ้างอิง และยังไม่มี OCR
  ไฟล์ที่สแกนมาเป็นภาพจะขึ้นสถานะ `needs_review`

## 7. จัดอันดับ แสดงผล และส่งออก

- **Rank & export → Compute ranking snapshot**
  - คะแนน = ความตรงของคำค้น (BM25) + ความคล้ายเชิงเนื้อหา + ความใหม่ของปี (ถ้าเลือก)
  - กดดูที่เอกสารเพื่อดูว่าแต่ละส่วนได้คะแนนเท่าไร
  - เอกสารที่ไม่มีข้อความเลยจะไม่มีคะแนน (ระบบไม่เดาให้)
  - คะแนนนี้ใช้ช่วยค้นหาเท่านั้น ไม่ได้วัดคุณภาพงานวิจัย
- **Visualize**: กราฟ 2D/3D ที่เลือกแกนได้
  - ลากเลือกจุดในกราฟ แล้วรายการเดียวกันจะถูกเลือกในคลังเอกสารด้วย
  - ด้านขวาแสดงว่ามีกี่จุดที่ไม่ได้แสดงเพราะข้อมูลขาด
- **Export**: ได้ไฟล์ ZIP ที่มีข้อมูล (CSV หรือ JSON), `manifest.json` และ README
  - `manifest.json` บันทึกคำค้น แหล่งข้อมูล วันที่ ตัวกรอง และเวอร์ชันการจัดอันดับ
  - ไฟล์ส่งออกไม่รวม PDF เพื่อเคารพลิขสิทธิ์

## 8. สิ่งที่ควรรู้

- ระบบเชื่อมกับ **OpenAlex** และ **Crossref** ในระยะที่ 1 แหล่งอื่น
  (Semantic Scholar, PubMed, arXiv ฯลฯ) อยู่ในแผนระยะที่ 2
- ค่าเริ่มต้นของ "ความคล้ายเชิงเนื้อหา" เป็นการวัดคำที่ซ้อนกัน ไม่ได้เข้าใจความหมายจริง
  ถ้าต้องการโมเดลภาษาจริง ให้ผู้ดูแลตั้ง `RIP_EMBEDDING_PROVIDER=sentence-transformers`
- ข้อมูลตัวอย่างที่มีป้าย **FIXTURE** เป็นข้อมูลสมมุติสำหรับทดลองเท่านั้น ไม่ใช่ผลการค้นหาจริง
